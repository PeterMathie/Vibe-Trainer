# Third-party anatomy assets

Vibe Trainer intends to use the open-source **MuscleMap** project for the anatomical body-map layer.

Repository: https://github.com/Jsplice/MuscleMap

The project states that its male-front, male-back, female-front and female-back vector muscle path data are original work licensed under MIT. Its asset provenance document also records the bundled body reference images as MIT-licensed.

Before release, copy the relevant licence text and any required attribution into the app's OSS notices screen and release bundle.
